# نور | نظام حلقات التحفيظ

واجهة أولية احترافية باللغة العربية لإدارة حلقات تحفيظ القرآن.

## الموجود في النموذج
- لوحة مشرف.
- إدارة الطلاب.
- الحضور والغياب.
- نظام النقاط حسب البنود المعتمدة.
- سجل النقاط مع فكرة التعديل حسب التاريخ.
- إنشاء المسابقات.
- تقارير قابلة للطباعة كـ PDF من المتصفح.
- لوحة شرف مخصصة للتلفزيون.
- تصميم RTL ومتجاوب للجوال.

## مهم
هذه نسخة Front-end تجريبية. تسجيل الدخول الحقيقي، قاعدة البيانات، الصلاحيات، حفظ البيانات على الإنترنت، توليد PDF من الخادم، والتحديث الفوري تحتاج Backend/Database.

## تشغيل محلي
افتح `index.html` في المتصفح.

## رفع على GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع `index.html` و`styles.css` و`app.js`.
3. من Settings > Pages اختر Deploy from a branch.
4. اختر Branch: main و Folder: /(root).
5. احفظ وانتظر ظهور رابط الموقع.

GitHub Pages مناسب للواجهة التجريبية. للنسخة الفعلية التي فيها حسابات وصلاحيات وحفظ نقاط، ستحتاج قاعدة بيانات وخدمة Backend.
