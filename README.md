# نور | حلقات التحفيظ

هذه حزمة واجهة أولية احترافية قابلة للرفع على GitHub Pages.

الموجود:
- لوحة متابعة
- طلاب الحلقة
- منح وخصومات متعددة الاختيار
- تاريخ العملية
- التحضير والغياب
- المسابقات
- التقارير
- شاشة مراكز للتلفزيون
